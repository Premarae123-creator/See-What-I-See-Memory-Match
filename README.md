# See What I See: Memory Match v1

Playable prototype with:
- Single Player
- Multiplayer rooms
- Classic Match
- Memory Flash
- Speed Match
- Turn Battle
- 9 themed categories
- Board choices from 8 to 36 cards
- Purple/gold See What I See-inspired UI
- Responsive mobile layout

## Render
Build command: `npm install`
Start command: `npm start`

Upload the repository preserving:
- server.js
- package.json
- public/index.html
