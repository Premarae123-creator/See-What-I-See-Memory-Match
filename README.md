# See What I See: Memory Match v7

New in v7
- PLAY AGAIN keeps multiplayer players in the SAME room. The host returns the existing room to its lobby and can start another round without generating a new code.
- Turn Battle renamed to HEAD TO HEAD.
- I See Money is now a multiplayer room mode for up to 32 players.
- Money cards have visible numbers 1–32 on their backs.
- Each player gets one number choice per Money round.
- A PLAYER PICKS panel shows each player and the number they selected.
- The single hidden $$ card determines the winner.
- Wrong Money picks shake, then fall off the screen, with a random voice line: Sorry / Maybe Next Time / Awwww / Nice Try.
- The Money winner gets a full-screen cash/winner animation.
- Existing room, results leaderboard, matching, camera/mic, Speed Match and Memory Flash features are retained.

Render
Build command: npm install
Start command: npm start
