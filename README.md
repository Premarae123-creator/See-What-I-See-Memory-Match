# See What I See: Memory Match v5
New:
- In-game leaderboard showing pairs/progress and elapsed time, plus locally saved best results.
- Normal mismatch says "Nope" using browser speech.
- New I See Money category.
- I See Money always uses a special 32-card board: 31 random picture cards + one $$ money card.
- Wrong Money picks randomly say: Sorry, Maybe Next Time, Awwww, or Nice Try.
- Finding $$ ends the round as the winner.
- Camera/mic and all v4 features retained.

Note: voice lines use the browser's built-in speech synthesis, so voice character varies by device/browser.
