# See What I See: Memory Match v9.4 — Waiting Room

New multiplayer waiting area:
- Every multiplayer room now has THE HANGOUT before gameplay.
- Players can gather in the room while the host waits to start.
- Camera ON/OFF and microphone ON/OFF are available in the lobby.
- Remote WebRTC streams are mirrored into the waiting-room player tiles.
- Players without camera enabled retain the See What I See avatar.
- Added live room text chat so players can communicate while waiting.
- Host crown remains visible.
- I See Money's number-lock selection remains inside the same lobby below the waiting area.
- Existing same-room next-round flow remains: after a game, host can change mode/category/card count without making a new room.

Note: peer-to-peer camera/audio still depends on network WebRTC traversal. TURN/SFU infrastructure is recommended later for production reliability.
